# N-TET 阿语网站文案审核与修订记录（2026-07-17）

## 审核口径

- 阿语站允许使用干扰、欺骗、反无人机、C-UAS 等行业与设备术语，包括 `تشويش`、`انتحال` 等对应阿语表达。
- 阿语文案不执行 A/B/C 广告风险分层审核；上述词语不作为阿语文案问题，也不要求中性化替换。
- 本轮重点是语言质量：英文回退、误译、占位符、重复词堆、术语不一致、RTL 混排和明显机器翻译腔。
- 产品型号、技术缩写、单位及无法可靠翻译的技术字段允许保留英文，以避免伪造含义。

## 技术参数处理原则

以下内容保留英文不视为翻译缺失：

- 型号与产品代号，例如 `FC-*`。
- 行业缩写，例如 `RF`、`EO/IR`、`Remote ID`、`C-UAS`。
- 数值、频段、接口与单位，例如 `MHz`、`GHz`、`V`、`W`、`IP65`。
- 无可靠术语映射的原始参数名；宁可保留可核对的英文，也不生成“技术值”或“N-TET 工业解决方案”一类无意义占位符。
