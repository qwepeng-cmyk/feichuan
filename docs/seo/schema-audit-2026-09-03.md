# N-TET Schema 审计

生成日期：2026-09-03

## 策略

- C-UAS 可索引记录可根据页面类型使用 Product、Service、Article、BreadcrumbList 与 Organization Schema。
- 不应用 A/B/C 或敏感词门禁。后台、API、preview、draft、未发布记录与非 C-UAS 页面不输出公开详情 Schema。
