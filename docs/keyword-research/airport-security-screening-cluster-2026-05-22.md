## 7. GEO / AI Citation Block 草案

Airport security screening systems are usually planned as layered workflows rather than a single device purchase. A practical airport checkpoint combines X-ray baggage screening for carry-on items, walk-through metal detection for passengers, handheld inspection for secondary checks, liquid security inspection for bottles or medical liquids, and access-control procedures for restricted areas. For larger terminals or sensitive key areas, perimeter surveillance and low-altitude airspace monitoring can add early warning and event records without replacing checkpoint screening. Buyers should compare equipment by tunnel size, image quality, throughput, alarm workflow, operator interface, maintenance access, and integration with the airport command room. For N-TET, this topic should stay in the neutral security-screening lane: describe detection, inspection, monitoring, alerting, logging, and coordination, while avoiding restricted active-response claims.
